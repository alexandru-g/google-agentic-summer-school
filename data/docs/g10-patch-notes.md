# Turbo Goat Simulator 9 — Patch Notes

## v9.4 — 2026-04-01

- Added couch co-op party modes: Goal Goat (football, sort of), Crumb Chase, and Demolition Derby
- Up to four goats on one screen; frame rate is now a shared responsibility
- Fixed a bug where the ice cream truck could achieve escape velocity. Re-added it as a mutator called "Escape Velocity"

## v9.3 "Goatnado" — 2025-07-15

- New event mode: Goatnado. Sixty goats. One tornado. Zero apologies.
- Performance warning: Goatnado is not optimized. It will never be optimized. This is a promise.
- Mayor Crumb now screams in slow motion when airborne for more than four seconds

## v9.1 "Bleatsburg Bash" — 2024-11-20

We heard the feedback that the fun runs out after a few hours. This one is for you.

- New district: the Marina, featuring a fully lickable ferry
- Added a 120-item challenge checklist with unlockable mutators (low gravity, rubber town, infinite tongue)
- 40 new physics props, including a grand piano and a portable trampoline
- Fixed goats phasing through the town hall floor. Community response was negative, so we un-fixed it.

## v9.0.2 — 2024-05-05

- Fixed a crash when licking the mayor during the ferris wheel cutscene
- Deliberately did not fix the funeral launch exploit
- Reduced load times by 30% so you can get to the nonsense faster
