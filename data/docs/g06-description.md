# Kernel Panic

**Genre:** Hacking roguelike | **Developer:** Null Pointer Games | **Released:** 2025 | **Price:** €12.99

You are a rogue process inside a dying machine, and your only weapon is the shell. Kernel Panic is a turn-based roguelike played entirely through a working command line: navigate directories as dungeon floors, grep ghosts out of log files, pipe enemies into /dev/null, and pray your fingers don't typo under pressure — permadeath doesn't care that you meant grep.

## Features

- Real shell mechanics: pipes, redirection, grep, chmod, cron, and man pages, all load-bearing
- Procedurally generated filesystems with seeded runs and daily challenges
- Daemon bosses, including the Kernel and the schedule-reading Cron Reaper
- Practice Sandbox mode: a consequence-free shell with a searchable in-game manual
- Artifacts that upgrade your shell itself, like tab completion and command history
- Chiptune soundtrack that compiles surprisingly hard

## System Requirements

- **OS:** 64-bit, 2014 or newer
- **CPU:** Dual-core 2.0 GHz
- **RAM:** 4 GB
- **GPU:** Anything that renders a terminal font
- **Storage:** 800 MB
- **Keyboard:** Mandatory. Sorry, controllers.
