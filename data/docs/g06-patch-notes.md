# Kernel Panic — Patch Notes

## v1.2 "Training Wheels, Sort Of" — 2025-11-13
- **New: Practice Sandbox** — a consequence-free shell where death just respawns you; built in direct response to feedback about the learning curve
- **New: in-game manual** — searchable man pages for every command, no more alt-tabbing to a wiki
- Optional hint daemon: whispers a suggested command after three deaths on the same floor (off by default, purists)
- First-run flow now offers Sandbox before your first real descent

## v1.1 — 2025-08-27
- New artifact: tab completion (floor six loot pool) — dramatically speeds up experienced runs
- Difficulty smoothing on floors one through three: fewer ambushes, more readable log clues
- Cron Reaper boss rework: its spawn schedule is now a real, readable crontab you can edit mid-fight if you're fast
- Fixed a crash when piping more than 256 enemies in a single command (we were impressed, though)

## v1.0 — 2025-06-05
- Launch release: 12 filesystem depths, 9 daemon bosses, seeded runs, daily challenges
- Known omission acknowledged in reviews: no tutorial. The machine does not explain itself. (See v1.2.)
