# Wizard Landlord — Patch Notes

## v1.3 — "Actual Economics" — 2025-10-02

- Fixed the Mimic Chest gold duplication exploit (for real this time — the pawn imp now remembers what he bought)
- Full rent formula rewrite: rent now scales with room size, district, and tenant species instead of a value one developer describes as "vibes"
- First pass on tenant pathfinding: imps should path around decorative walls instead of into them
- Added Hard Mode ("Audited") with upkeep costs and tax season

## v1.2 — "Balance of Power" — 2025-03-06

- Attempted fix for a gold duplication exploit involving the Mimic Chest (known issue: exploit may persist in some inventory states)
- Rebalanced rent for goblin and dragon tenants
- 30 new complaint letters

## v1.1 — "Tenants' Rights" — 2024-09-12

- Added tenant unions and group demand events
- New tenant species: banshee, stone golem
- Fixed werewolves blaming incidents on tenants in other towers

## v1.0 — Launch — 2024-04-18

- Wizard Landlord releases with 3 towers, 14 tenant species, and 400 hand-written complaint letters
